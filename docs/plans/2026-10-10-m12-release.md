# 里程碑 12 计划：发布准备

日期：2026-10-10
来源：[路线图](2026-09-23-v1-milestone-roadmap.md)「M12 发布准备」与遗留项归属表里归到 M12 的条目
状态：进行中

## 目标

把 Syndica 整理成可公开发布的 v1.0：公开 API 冻结、英文用户文档与文档站、仓库规范、打包与发布配置、CI 矩阵、
demo，并通过路线图列出的四项 E2E 验收。推送、发 PyPI、把仓库设为公开、打 v1.0 标签之前问用户。

## 已定的决定（用户 2026-10-10 选定）

- **D1 CI**：本月没有 GitHub Actions 额度。`ci.yml` 按矩阵写好，本月在本地跑通（macOS 原生、Colima 里的 Linux
  容器、uv 装的 3.11 / 3.12 / 3.13）；额度恢复后用托管 runner 跑一次完整矩阵，作为发布门禁。
- **D2 平台**：v1.0 只支持 Linux 与 macOS；Windows 用户用 WSL2。代码里进程组、`setsid`、伪终端这些 POSIX 接口不加
  Windows 分支；包元数据不声明 Windows。
- **D3 语言**：只英文化用户文档与文档站（README、五分钟上手、概念、API 参考、排错、扩展指南）。运行时的错误
  信息、CLI 输出与代码注释保持中文，文档写明；英文化归 v1.x。AGENTS.md 按它自己的要求译成英文。
- **D4 发行形态**：单个发行包 `syndica` 加 extras（`server` / `openai` / `otel` / `mcp` / `acp` / `a2a` / `trl`），
  不拆成 `syndica-server` / `syndica-runner`。依赖体积靠 extras 控制，分层由 `check_deps` 强制。路线图静态验收里的
  `pip install syndica-server` 换成 `pip install 'syndica[server]'`。

## 硬约束

- 公开面加名字不破坏、去名字破坏：v1.0 之前撤下的每个名字都写进 CHANGELOG 与快照的 diff。
- 快照由人 review：快照变化即公开面变化，测试失败时先看 diff，再决定改快照还是改代码。
- 文档里的命令要么被测试执行或解析，要么明确标为不执行。
- SECURITY 写明：不提供多租户隔离；同进程的第三方代码（Module、backend）无法沙箱化。
- 不发 PyPI、不打标签、不设仓库公开、不推送，除非用户确认。

## 验收

路线图的静态验收与 E2E 验收，按 D1–D4 调整：

- `pip install .`、`pip install '.[openai]'`、`pip install '.[server]'` 等每个 extra 的 smoke 通过。
- 本地矩阵（macOS 与 Linux 容器 × 3.11 / 3.12 / 3.13）全绿；`ci.yml` 写好托管矩阵，下月作发布门禁。
- 文档站构建无断链；README 代码块可执行或明确标记不可执行。
- 包元数据、license、classifiers、`py.typed` 完整。
- 公开 API 快照与 v1.0 冻结清单一致。
- 依赖锁与安全扫描无高危未解释项。
- E2E：干净 Linux 容器里照 README 五分钟内完成一次 CLI run；Web UI 完成多 Agent 任务、人工确认、查看产物；
  MCP / OpenAI SDK 连本地 server 完成一次工具调用；跑一批任务并导出训练数据。

## 明确不做

- Windows 支持（D2）。
- 运行时信息的英文化与本地化（D3）。
- 拆分发行包（D4）。
- 多 Agent 子树持久化（路线图归 v1 之后）；回放文档 v4 与其余标「后续」的遗留项。
