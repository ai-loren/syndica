## M12 交付了什么

用户 2026-10-10 选定四件事：本月 CI 在本地验证、托管矩阵下月作发布门禁；只支持 Linux 与 macOS（Windows 用 WSL2）；
只英文化用户文档，运行时信息保持中文；单包加 extras。

- **公开 API 冻结**：公开导入路径是 `syndica`、`syndica.kernel`、`syndica.kernel.contracts`、`syndica.runner` 与四个
  backend；快照 `tests/testdata/public_api.json` 由测试逐字节比对，英文参考页由它生成。撤下 `provenance_of`、
  `strictest_trust`；长程策略协议与契约、`ArtifactHandler` 转正，第三方经 `RuntimeModule(artifact_handlers=...)` 装处理器。
- **英文文档**：README 改写；`docs/user/` 32 页的 MkDocs 站，严格构建；每个代码块要么被测、要么写明不测的理由。
  AGENTS.md 译成英文。
- **打包**：`1.0.0rc1`、SPDX 许可证、只声明 Linux / macOS、`py.typed` 与前端静态资源进 wheel、`check_dist.py`、
  `smoke_install.sh`、`SHA256SUMS`；CHANGELOG、版本与弃用策略、发布流程；CONTRIBUTING、行为准则、SECURITY、模板。
- **CI**：`ci.yml` 扩成 ubuntu / macos × 3.11–3.13，加前端、打包、安全扫描；`scripts/local_ci.sh` 在导出的提交上跑同样
  的几格。依赖安全扫描 0 个漏洞。
- **demo 与验收**：`examples/` 下四个 demo；`scripts/acceptance.sh` 从构建出的 wheel 跑路线图的四项 E2E，全部通过。
- **查出并修掉的缺陷**：9 个，见 M12 审计。其中三个只在 Linux 或 3.12 / 3.13 上出现，一个只在照 README 真实安装时出现。
