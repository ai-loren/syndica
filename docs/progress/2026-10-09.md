## 各里程碑交付了什么

完成判据与证据在 [spec §15](../design/2026-09-03-architecture.md)（状态写到 2026-10-08）和上表的收口审计里。下面是读这一份就能对上的交付：

- **M1（2026-09-23）** 内核骨架：多个 Agent、互发消息、各自的「LLM + 工具」循环、声明式角色、拓扑装配、最小本地执行。2026-09-29 用免费模型跑通体验验收，并加上多平台轮换（Gemini 在前、OpenRouter 兜底，每个平台各自退避）。
- **M2（2026-10-01）** 自举：免费模型按本仓 `syndica-dev` 拓扑，在仓库副本里改了一处交接文字并补了用例；人选择后由宿主提交，那个提交进了本仓。CLI 可用。
- **M3（2026-10-02）** 每次 run 一个 trace（span、派生边与消息边），默认可离线回放；`syndica trace` 读、回放、导出、清理。落盘与导出先过内核的 `Redactor`。
- **M4（2026-10-03）** 第三方能力经入口点装成 Runtime Module（清单、Flag、工具与插件、启停钩子），显式启用、受信任确认约束，输出一律不可信。Flag 文档由声明生成。
- **M5（2026-10-04）** `Workspace` / `Portal` 全量接口与契约套件、用纯 Python 写 git 对象的版本层、worktree 与快照隔离、共享模式的写入冲突、伪终端。文件污点与溯源：命令改过的文件、外部改动、读过不可信内容之后的写入都读回成不可信；执行工作区里不可信的脚本强制升级。
- **M6（2026-10-05）** 根对话的会话持久化与恢复。压缩交付了规则、剪枝、摘要三种；目标导向型依赖 Rubric，随 M8 补上。两层记忆：LLM 整理，只有根写全局，不可信不进全局。多 Agent 子树不在这一里程碑持久化。
- **M7（2026-10-06）** 产物有身份与版本，`Deliver` 标交付物，处理器按 `(kind, mime)` 注册。Goal 是权威，Rubric 是带锚点的投影。L1 / L2 / L3 验收做成 Module，裁决是四值（`pass` / `partial` / `block` / `unverified`），由内核推导。人的反馈要 `sessions activate` 之后才生效。
- **M8（2026-10-06）** 预算树（轮次 / token / 成本 / 墙钟，按预留记账）、`GetBudget` 与 50 / 25 / 10% 提醒、进度只从验收的确定结论量、完成 / 资源 / 停滞三条停止判据、可插拔长程策略、目标导向型压缩与压缩前完整前像、后台工具、派活树回收。截止时刻打断正在跑的一轮在 M9 做完；子树持久化改派到 v1 之后。
- **M9** 见下一节。**M10** 见「里程碑 10」。
- **M11（未推送）** 中立轨迹 `syndica.trajectory/1`，从会话、Goal / Rubric、trace 与产物登记拼出；SFT（OpenAI 消息与 ShareGPT）、偏好（同一 Goal 与同一份 Rubric 下配对）、RL（token id、loss mask、按裁决的 reward）；`syndica batch` 与 `syndica export`；`syndica[trl]` 的 dry-run 把导出的 SFT 文件喂进 `SFTTrainer`。`unverified` 默认排除。

## 里程碑 10：当前进度

### 已定的决策（用户 2026-10-09 选定）

1. 官方 SDK 各进各的可选 extra：`syndica[mcp]`（`mcp` 2.3）、`syndica[acp]`（`agent-client-protocol` 0.12）、
   `syndica[a2a]`（`a2a-sdk` 1.2）；OpenAI 兼容 HTTP 挂在 `syndica up` 上、不引 SDK（`openai` 只进 `dev` 当测试客户端）。
2. MCP server 缺省只暴露只读工具（Read / Grep / Glob，产物作 resources、角色作 prompts）；写与命令类在配置里显式打开，
   仍过危险判定，高风险没人可问时直接拒绝。
3. ACP 双向：第三方客户端（编辑器等）驱动 Syndica；Syndica 托管第三方 ACP Agent（如 Gemini CLI），它的读写文件与终端
   由 Syndica 的工作区与安全层提供。
4. 托管的 ACP Agent 与远端 A2A Agent 以**角色**出现（CLI、Web 建会话可选，Orchestrator 可派活给它），输出一律不可信。
5. OpenAI 兼容 HTTP 同时做 chat completions 与 Responses（文本、function call、streaming）。
6. 机器客户端的令牌由 `syndica up --api-token` 打印在人的终端，只在 server 内存里、重启失效、不落盘。
7. 外部进程与远端要的密钥只从工作区之外的用户级配置 `interop.yaml` 来，项目配置只能按名字引用、不能点名密钥。
8. 可以在临时目录装第三方 CLI（MCP Inspector、Gemini CLI）、用免费 Gemini key 跑真实场景（key 只在子壳里 source）。

- 墙钟到点发 `session/cancel`，等不到就杀整组（含孙进程）。对端崩溃只报异常类型，不回显原文，且不自动重连。
- `model: acp:<名字>` 由组合根解析。宿主在 Runtime 建好后 `bind_runtime`：工具、处置、Agent 环境，再叠上用户级点名的变量。会话结束时 `aclose`。

### 阶段一已经落地（未提交）

  工具名 `<server>__<tool>`，`$ref` 内联，有环或超深的工具排除并记 ERROR；结果一律不可信；调用串行；超时取服务超时与墙钟剩余的较小者；
  断连交回三件套且不自动重连。stderr 先脱敏再记，超过上限仍继续读。
- 危险规则 `mcp.external_tool`：配置的 high / low 优先，否则 `readOnlyHint` 且 `destructiveHint` 不为真才是 LOW。开发期处置表对这条规则是 CONFIRM。
